# Kandidatsprites v0.37

Fyra SVG-poser med penselliknande tygretusch och deras PNG-filer. Retuschen kommer från färgprover i godkänd originalillustration och klipps till byxbenens faktiska form. `cycle-preview/` innehåller 4 oförändrade godkända originalbilder + 4 nya kandidater med fotankare y=205. `manifest.json` och `cycle-manifest.json` innehåller proveniens och SHA-256.

**Inte färdig handritad gångcykel, inte inlagd i spelet.** Källmaterialet v0.36 och originalproduktionsbilderna är oförändrade. Läs `docs/V037_ART_STUDY.md` i projektroten.
