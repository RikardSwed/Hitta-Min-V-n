# v0.35 — två illustrerade provposer (inte spelgrafik än)

Två fristående PNG och två redigerbara SVG (220×220).

**Vad som är nytt:** Individuellt tecknade SVG-byxben/konturer, knäveck, tyngd och skoposition för kontakt respektive passage.
**Vad som är återanvänt:** Huvud, hår, ansikte, huva, armar, överkropp och sneakers ur godkänt original.
**Status:** Inte helt handmålade helkroppsposer. Detta är ett produktionsprov och ersätter inte spelgrafiken.

Granska först vid 1× och 3× storlek; om övergångar och stil håller, skapa motsatta kontakt-/passagesteg och därefter en komplett gångcykel.
