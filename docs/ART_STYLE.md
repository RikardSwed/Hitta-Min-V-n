# Grafisk riktning

## Beslutad stil
Ljus, vänlig, handritad 2D med rena konturer, mjuk cel-shading, pastellfärgade himlar, gröna parker, detaljerade moderna stadsmiljöer. Egen visuell identitet; inte kopiera skyddade spelresurser.

## Huvudperson
Blond, tonårig pojke i vit huvtröja med röd huva, mörka byxor och sneakers, ryggsäck, svärd. Behåll siluett och färger konsekvent i framtida bilder. Se `assets/characters/hero-school-concept.png`.

## Aktuella bildresurser
- `assets/characters/hero-school-concept.png`: frilagd figur från vår konceptskiss. Används som tillfällig spelgrafik, inte färdig animation.
- `assets/backgrounds/park-concept.png`: utsnitt ur konceptskiss, visas som diskret parallaxlager.
- Canvas ritar fortfarande plattformar, träd, objekt, fiender och ljuseffekter proceduralt.

## Kommande spriteproduktion
Separata transparenta PNG-bildrutor/spritesheets med enhetlig figurstorlek, pivotpunkt vid fötterna och kontrollerade kollisionsrutor. Animationsbehov: idle 4–6, gång 6–8, hopp/landning 5–7, duckning 2–3, svärd 5–7, framåtvolt 6–8, skada 3–4. Bildrutor måste kvalitetsgranskas före integrering.

## Miljöer
Stadspark: fontän, lyktstolpar, stenplattformar, parkbänkar, stora träd och siluett av stadens skyline. Framtida banor följer samma tecknade stil.
